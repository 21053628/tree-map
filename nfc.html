🌳 NFC 樹木導覽系統

📱 什麼是 NFC 樹木標籤？

NFC（近場通訊）標籤是一種小型晶片，可以儲存網址資訊。當市民用手机掃描樹木上的 NFC 標籤時，會自動：

  • ✅ 直接開啟該樹木的詳情頁面
  • ✅ 在地圖上顯示樹木位置
  • ✅ 查看樹木資料、巡查記錄

🔧 設定步驟

步驟 1：準備 NFC 標籤

購買可寫入的 NFC 標籤貼紙（建議 NTAG213 或 NTAG215）

💡 使用方法：
1. 複製上方網址
2. 使用 NFC 寫入 App（如「NFC Tools」）將網址寫入 NFC 標籤
3. 將 NFC 標籤貼在樹木標示牌上

步驟 3：測試 NFC 標籤

寫入完成後，用手机掃描 NFC 標籤，應該會：

  1. 自動開啟瀏覽器
  2. 跳轉到主地圖頁面（index.html）並自動定位到該樹木
  3. 地圖會顯示該樹木的位置和詳細資訊
  4. 點擊樹木標記可查看完整資料或前往樹木詳情頁

❓ 常見問題

Q: 需要安裝 App 才能掃描嗎？
A: 不需要！現代智慧型手機（iPhone 和 Android）都內建 NFC 讀取功能，直接靠近即可。

Q: NFC 標籤在哪裡購買？
A: 可在網上購物平台搜尋「NFC 標籤貼紙」或「NTAG215」，價格便宜。

Q: 如何修改已寫入的 NFC 標籤？
A: 使用 NFC Tools 等 App 可以重新寫入新的網址。
