    ❓ 常見問題

    Q: 標籤買哪種？
    推薦 NTAG215（504 bytes，防水貼紙），淘寶或 HKTVmall 都有。

    Q: iPhone 可以掃嗎？
    可以！iPhone XS 之後的機型支援背景 NFC 讀取，靠近就會彈出通知。

    Q: iPhone 如何寫入？
    iOS 不支援 Web NFC 直寫，需使用「NFC Tools」App（App Store 免費下載）配合「手動複製」分頁的 URL。

    📖 NFC 技術說明

    標籤容量對照

    型號可用容量建議用途
    NTAG213144 bytes極短網址，容量吃緊
    NTAG215504 bytes✅ 推薦，綽綽有餘
    NTAG216888 bytes長網址 / 進階用途

    什麼是 NDEF？

    NDEF（NFC Data Exchange Format）是 NFC 標籤的標準資料格式。寫入 URL 記錄後，任何支援 NFC 的手機靠近標籤，都會自動彈出「開啟網頁」的提示。

    寫入後如何驗證？

    使用本頁「🔍 讀取標籤內容」按鈕，或直接用手機掃描，確認開啟的是正確的樹木頁面。

    標籤耐用性建議

    樹木在戶外環境，建議選用 抗 UV / 防水貼紙，避免日曬雨淋導致標籤老化退色。若需黏貼在金屬表面，請選用「抗金屬」款式。

    權限說明

    首次使用 Web NFC 寫入時，瀏覽器會跳出權限請求。若誤按拒絕，可到 Chrome 的「網站設定 → NFC」重新開啟。

    安全提醒

    寫入的網址為明碼，任何能掃描 NFC 的人都能讀取。本系統不涉及敏感資料，但請勿寫入個資或機密。
